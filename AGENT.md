# AGENT.md

## How to proceed tasks

When you work with numbered tasks in the `docs/task.md`,

- You must reference `docs/task.md` to see entire tasks and inter-task relationships.
- You must reference `docs/tasks` to see each tasks.
- You must reference `docs/mermaid-editor-sdk` to see purpose and design of this project.
- You must reference `https://github.com/NextGenPowerToys/mermaid-visual-editor`. This is because the SDK is created by properly restructuring and separating the original repository.
- When You work with screen or UI/UX, You must reference `docs/ux-ui/UI-UX-WIREFRAME.md`. Here are the specifications that users need to see and experience.

Before you mark task is resolved, Analyze the differences between the original repository and the design document. Analyze whether this is an intentional difference or an omission, and if it is an omission, correct it.
Report any intentional deviations to me for review. I will then direct the follow-up actions or instruct you to wrap up the matter.

## Branch and Commit

- **DO NOT CREATE GIT BRANCH**
- Work in main and commit to main.
- If you make branch and work on the branch, you replace commit to main and delete the branch
