# SDK UI Storybook

An isolated Storybook workspace for inspecting the React UI exported by `@mermaid-editor-sdk/ui`.

```sh
pnpm storybook
```

Open <http://localhost:6006>. The `Components` section has a story for each public React component. Complex components use a small flowchart fixture so the palette, canvas, selection dialog, and editor can be inspected with realistic props.
